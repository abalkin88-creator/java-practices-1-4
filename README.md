## Запуск

Нужен JDK 17. Кодировка исходников — UTF-8.

В IntelliJ IDEA откройте папку репозитория, выберите JDK 17 и отметьте `src` как Sources Root, если среда не сделает это автоматически. Откройте нужный класс с методом `main` и запустите его. Классы для запуска указаны в описаниях заданий.

Из терминала в корне репозитория:

```text
javac -encoding UTF-8 -d out @sources.txt
java -cp out practice1.ArrayFor
```

Для программ с `Scanner` данные вводятся в консоль после запуска. Для `practice1.Arguments` параметры передаются при запуске:

```text
java -cp out practice1.Arguments Java Практика 1
```

`TestAuthor`, `TestShape`, `TestMovable` и другие классы с `Test` демонстрируют работу соответствующих классов и запускаются обычным методом `main`.
