# Практическая работа 1

## Финал — все задания в одном файле

**Для показа и запуска откройте [Final.java](Final.java).** В нём собраны все задания практики с подписями.

В IntelliJ IDEA запустите `Final.main()`, введите номер нужного задания из меню и затем данные, которые оно запросит. После завершения задания запустите файл снова, чтобы выбрать другое.

Файл можно компилировать отдельно от остальных исходников. Из корня репозитория:

```text
javac -encoding UTF-8 -d out src/practice1/Final.java
java -cp out practice1.Final
```

Для задания 5 с аргументами командной строки:

```text
java -cp out practice1.Final 5 Java Практика 1
```

## Исходные файлы по заданиям
## Синтаксис и управляющие конструкции

Пункты 1, 2 и 8 относятся к созданию проекта, Git-репозитория и публикации исходников. Программные задания 3–7 приведены ниже.

### Задание 3 Сумма и среднее арифметическое

Создать целочисленный массив с помощью инициализации. В цикле for вычислить сумму его элементов и среднее арифметическое. Вывести результаты на экран.

- [ArrayFor.java](ArrayFor.java)

Класс для запуска: `practice1.ArrayFor`.

### Задание 4 Ввод массива и циклы while и do while

Ввести массив с клавиатуры. Найти сумму элементов циклами while и do-while, определить минимальный и максимальный элементы.

- [ArrayInput.java](ArrayInput.java)

Класс для запуска: `practice1.ArrayInput`.

Пример ввода:

```text
5
7 -4 12 0 5
```

### Задание 5 Аргументы командной строки

Вывести аргументы командной строки в цикле for.

- [Arguments.java](Arguments.java)

Класс для запуска: `practice1.Arguments`.

Аргументы запуска: `Java Практика 1`.

### Задание 6 Гармонический ряд

Вывести первые десять членов гармонического ряда 1, 1/2, 1/3, ... с форматированием результата.

- [Harmonic.java](Harmonic.java)

Класс для запуска: `practice1.Harmonic`.

### Задание 7 Факториал

Реализовать метод класса для вычисления факториала с помощью цикла. Проверить его работу.

- [Factorial.java](Factorial.java)

Класс для запуска: `practice1.Factorial`.
