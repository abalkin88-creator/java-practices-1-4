## Как запустить

Нужен JDK 17, кодировка UTF-8. В IntelliJ IDEA откройте папку репозитория, выберите JDK 17 и отметьте `src` как Sources Root. В нужной папке `practice1`, `practice2`, `practice3` или `practice4` откройте `Final.java` и запустите метод `main`.

Введите номер задания из меню. Если программа попросит массив, логин или другие данные, введите их в ту же консоль. Чтобы выбрать другое задание, запустите файл снова.

Каждый `Final.java` компилируется самостоятельно. Например, из корня репозитория:

```text
javac -encoding UTF-8 -d out src/practice4/Final.java
java -cp out practice4.Final
```

Номер задания также можно передать аргументом запуска. Для задания 5 первой практики остальные аргументы передаются самой программе:

```text
javac -encoding UTF-8 -d out src/practice1/Final.java
java -cp out practice1.Final 5 Java Практика 1
```

## Изначальные отдельные файлы

Исходные классы сохранены в папках практик; ссылки на них находятся в описаниях заданий. В том числе оставлены `Author.java`, `TestAuthor.java` и `Movable.java`, используемые в материалах.

Чтобы скомпилировать весь репозиторий:

```text
javac -encoding UTF-8 -d out @sources.txt
```
